# GSI 어드민 — 퍼블리싱·개발 인계 (26-09-14)

이 폴더가 인계물 전부다. **코드 + 기능 정의** 두 갈래로만 구성했다.

```
gsi-admin/          코드 — 사용자 웹 (편성표 · 프로그램 상세 분석 · 실시간 현황)
channel-placement/  코드 — 어드민 웹 채널배치 시뮬레이터 (KT 내부 담당자용)
기능정의/            무엇을 만들어야 하나 · 더미를 어디서 실데이터로 바꾸나
```

코드 폴더는 바깥을 참조하지 않는다 — 통째로 복사해 아무 정적 서버로 열면 된다.
사업 배경·사용자 정의·설계 방향 등 **기획 문서는 KT 를 통해 별도로 전달**된다.

   - 같은 내용의 화면 캡처판: `기능정의/GSI-정의서.pptx` / `.pdf` (35장, 편성표 + 프로그램 상세 분석. 화면 지도 → 부위별 확대 → 기능표 순)
2. `기능정의/HANDOFF.md` — 개발 인계: 기능 명세 + **더미 ↔ 실데이터 접합 지점** + 보류 기능
3. `gsi-admin/README.md` — 파일 지도 · CSS 적용 순서 · 퍼블리셔 주의
4. `gsi-admin/HANDOFF-KT-260820.md` · `HANDOFF-KT-260824.md` · `HANDOFF-KT-260828.md` — KT 수정요구(8/20 14건 · 8/24 10건 + 8/25 후속 · 8/27 6건 + 8/28 10건) 반영 현황 + 개발사 몫 + **KT 확인 필요 항목**
