## A1. 편성표 — "조회조건이 뷰를 결정한다"

- **자동 뷰 전환**: 단일 날짜 조회 = 성과 인코딩 타임라인(기본) / 기간·요일 다중·프로그램명 검색 = 리스트. 토글 컨트롤 신설 없음 — 뷰는 데이터 형태의 귀결. 현재 뷰는 실제품 장르탭 문법으로 표시(수동 재선택도 그 탭으로)
- **첫 진입 기본 = 어제 날짜**(MD 아침 동선), 타임라인 → **[26-08-20 KT 수정안 #1 로 대체] 디폴트 = 최근 1달(리스트 뷰), 기간 오른쪽에 요일·시간대 필터(시작시간 기준)**. 단일 날짜를 고르면 타임라인으로 — 자동 뷰 전환 원칙은 유지
- **Now선 제거** — 배치 데이터에 라이브 장치는 스펙 위반(PRD C-2). ON AIR 빨강은 당일 조회 한정 유지
- **블록 잔류 필드(KT 확정)**: 프로그램명·편성시간·담기 3개. 10분 이하 블록은 프로그램명만. 이미지·카테고리·가격·시청·콜 = 호버 팝오버. 홈쇼핑사명/로고 = 채널 행 레이블, 편성일 = 시간축 날짜 뱃지
- **성과 인코딩**: 시청 규모 = 블록 배경 채도(폭 무관) / 콜 = 우상단 도트 3단계 + 툴팁 수치 병기. ~~스파크라인~~ 폐기(작성자 철회: "10분 폭 73px에선 얼룩")
- **숫자의 자리 = 채널행 우측 고정 성과 레일**(시청·콜 2값) + 체크 선택 시 하단 비교표 — 블록 폭 문제를 구조로 우회(서윤 3층 분리, 외주사 개발 지지)
- 최소 폭 플로어 44px 적용 블록엔 길이 왜곡 표식(“길이=시간” 문법 보호)
- 리스트 뷰에도 규모 미니바 인코딩 유지 — 형식이 바뀌어도 "그래서 잘했나"는 유지
