# PRD — KT GSI 시청행태 분석 고도화 (프로그램별 2페이지)

작성 2026-08-01 · 근거 = 26-07-10 KT 초기 요구사항 + GSI 원본 자료(KT 제공).

---

## 1. 배경

- 제품 = **GSI (G Shopping Insight)**, KT TV 홈쇼핑 데이터 분석 어드민. 사용자웹(홈쇼핑 관계자용) + 어드민웹(KT 임직원용) 2접속 체계.
- KT는 셋탑박스 기반 **시청 데이터**(유입/유출/시청)와 KT 모바일 연동 **반응 데이터**(전화·검색)를 보유.
- 이번 과업 = 사용자웹 **시청행태 분석 > 프로그램별** 신규 2페이지. 기존 화면 체계·디자인 가이드 안에서 데이터 표현만 신규.

## 2. 사용자와 목적

| 사용자 | 화면 | 목적 | 근거 |
|---|---|---|---|
| 홈쇼핑사 PD | 실시간 현황 (기존, 이번 범위 아님) | 라이브 중 시청 반응 보고 멘트·스팟으로 매출 극대화 | |
| **홈쇼핑사 MD·마케터 (핵심)** | **시청행태 분석 (이번 범위)** | 방송 종료 후 보고서 작성 + 과거 성과 근거로 상품 소싱 결정 | |
| KT 임직원 | 채널배치 최적화 (보류) | 채널 배치 시뮬레이션 | |

**UX 원칙** — IT 비전문가인 홈쇼핑사 담당자가 여러 번 클릭하지 않고 한 번에 직관적으로 이해할 수 있어야 한다. 밀도보다 명료성.

## 3. 도메인 전제 (설계를 구속하는 사실)

1. **배치 데이터다.** 시청행태 분석은 방송 종료 30분 후(현재 4시간 주기, 30분 단축은 KT 별도 작업 — 우리 몫 아님)부터 조회 가능. → 화면에 라이브 장치(진행바·현재시각·LIVE 뱃지) 금지, 집계 기준 타임스탬프 필수.
2. **관점 = 자사 홈쇼핑사**(예: GS샵). 유입 채널 = 자사 채널로 들어온 출처(KBS2→GS 등). 인접 채널이 뭘 파는지 + **경쟁 홈쇼핑사가 뭘 팔고 있는지**가 중요 — 06 EPG가 경쟁 4사 상품·성과를 나란히 보여주는 근거.
3. **측정 단위 = 셋탑박스(세대주 계약)** → 가구 구성·연령·남녀·관심사(외부 연동)가 따라옴.
4. **반응 데이터의 대표 KPI = 전화(콜).** 검색보다 중요.
5. 추가 확보 가능한 데이터는 없음. 디자이너 판단으로 파생 지표 추가는 허용.
