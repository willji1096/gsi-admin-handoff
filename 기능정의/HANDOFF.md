## 2. 편성표(schedule.html) — 기능 명세

### 2.1 화면 골격
GNB(60, sticky) → 헤더 존(브레드크럼 · H1 · 설명, 흰 면 + 하단 헤어라인) → `page-wrap`(gray-100 바닥, 카드 사이 24) → KT 풋터. 하단에 분석 바구니 바(sticky, 64) 고정, 우하단 위로가기 버튼(400px 이상 스크롤 시 표시).

### 2.2 조회 조건 (상시 펼침) — 26-08-20 KT #1·#4 반영
- 조회 기간: from/to 필 클릭 → 달력(`.cal`) — 최대 31일, 초과 시 필드 에러 + 조회 버튼 잠금. **첫 진입 디폴트 = 최근 1개월**
- **요일**: 월~일 7칩 토글(`#dowRow`, 전체 켜짐이 기본 = 필터 없음)
- **시간대**: 시작~종료 시각을 직접 고른다(`#hourFrom`·`#hourTo`, 00시~23시 select, 디폴트 00–23 = 전체). 구간은 하나.
  - **기준 = 프로그램 시작 시간.** 09–12 이면 09:00~12:59 에 시작한 편성이 걸린다
  - 26-08-25 KT 요청으로 3시간 8구간 칩 → 시각 직접 선택으로 바뀌었다("홈쇼핑사마다 니즈가 달라서 조회 기간처럼 시간대도 그냥 고르게"). 구간 칩 마크업은 `schedule.html` 에 주석으로 남아 있다
  - 컴포넌트는 **조회 기간 날짜 필과 같은 `.pill`**(44 · r22 · 좌우 24 · 아이콘 16) — 같은 줄에서 규격이 갈리지 않게
- 홈쇼핑사 17 · 일반채널 14 · **공통카테고리 12**(26-08-20 KT #4): 토글 칩 + `전체 선택`
  - 카테고리 칩은 **필터가 아니라 강조**다 — 켜도 전 프로그램이 그대로 보이고 해당 블록만 색이 붙는다
- 프로그램명 검색: 입력 즉시 반영 (서버에선 LIKE)
- 엑셀 다운로드: 파일명 `종합편성표_YYYYMMDD_YYYYMMDD.xlsx`, **생성은 서버 몫**(목업은 토스트만)
- 초기화 / 조회

### 2.3 조회 결과 — 뷰 자동 전환 규칙
- 기간이 하루 & 검색어 없음 → **타임라인** 권장, 그 외 → **리스트** 권장. 사용자가 탭을 직접 누르면(`manual`) 권장을 무시하되, 탭 행에 "조회 조건 기준 권장: …" 노트를 띄운다.

### 2.4 타임라인 뷰
- 시간축 24h, 1분 = 4px(하루 5,760px 가로 스크롤). 축 왼끝/오른끝에 그날·다음날 날짜 배지.
- **날짜 스테퍼** `‹ 06.18(목) ›`: 하루씩 이동. 라벨 클릭 → 달력(하루 선택 모드, 기준일 이후 잠금). ‹› 400ms 이상 누르면 120ms 간격 연속 이동. 달력은 스크롤 시작 시 닫힘. 기준일(06.19) 이후는 › 비활성.
- **채널 순서** 세그먼트 `구분 | 번호순`: 구분 = 홈쇼핑 위·일반채널 회색 밴드 아래 / 번호순 = 둘을 채널 번호 하나로 섞음. 두 모드 모두 자사(KT알파) 행은 맨 위 고정.
- **미니맵**(24h 폭 위 현재 창): 창 안을 잡으면 그 자리 그대로 드래그(offset 유지), 창 밖 클릭은 그 지점으로 점프, 휠 = 가로 스크롤, 히트 영역 위아래 6px 여유. 키보드 ←→ 1시간.
- 채널 행: 검정 **채널 번호 칩** + 로고 + 사명(자사 `자사` 태그). 일반채널도 번호 표기(SBS 5·KBS2 7·KBS1 9·MBC 11).
- 블록: 시청자수 히트 3단(`tl__blk--l1~3` — 그날 화면 블록의 p75/p90 기준) · 미집계(`--pending`) · 폭에 따라 `--tiny`(<30분: 제목만)/`--mid`. 콜 확정 블록엔 우상단 콜 도트.
- 호버 팝오버(250ms 지연): 상품 사진 · 제목 · 카테고리/날짜/시간/가격 · 시청자수+상태칩 · 콜 수+상태칩 · 기준시각. 상태칩 3종: 확정(초록 ✓) / 잠정(노랑 !) / **집계 중(회색, 로더 회전)**.
- 블록 클릭 = 바구니 담기/빼기(**최대 9** = KT 바구니·상세 상한, 26-08-20 KT #7 로 5→9. 시청 미집계 편성은 담기 불가).
- 우측 고정 레일 "채널 하루 성과": 시청 합계 · 콜 합계(콜 미확정이면 줄 비움).
- 스크롤 시 채널 열(sticky) 밑으로 들어가는 축 라벨·블록 글자는 통째로 감춤(`is-clipped`).

### 2.5 리스트 뷰

## 3. 상세 분석(analysis.html) — KT 페이지 위에 구현해야 할 것

analysis.html 은 KT 원본(Next.js 캡처)을 그대로 두고 아래를 **스크립트로 주입**해 놓은 목업이다. 각 항목은 원본 페이지에 네이티브로 넣어야 한다. 주입 코드는 파일 뒷부분 `<style id="gsiHdrPatch">`(10,950줄)부터 끝까지 `id="gsi…"` 스크립트·스타일 블록과 `gpie`·`ktc4`·`kth2` 블록에 모여 있고, 각 함수가 곧 명세다(`mix3` 채널별 결과 구성 카드는 26-08-30 걷어냄). 파일 맨 위 안내 주석부터 읽을 것.

### 3.1 GNB (`inject`)
GSI GNB — 편성표와 동일(로고 · 6메뉴 · 기준시각 · 툴 아이콘 3 · 계정). KT 원본의 `nav.sticky.top-0.z-40` 은 숨김. 메뉴 활성 = 시청행태 분석.

### 3.2 헤더 존 (`injectTop`) · 프로그램 전환 바 (`injectProg`) — 26-08-25 개편
```
[시청행태 분석][프로그램별 상세 분석] [K KT알파 쇼핑][일반채널 KBS1, KBS2, MBC, SBS]
[←] 원피스 썸머 특집                              [프로그램명|편성일자|편성 시간|가격|카테고리]
분석 대상 [KT알파 직화 불고기][현대홈쇼핑 건강즙]…(편성표에서 담은 것 최대 9) │ [CJ ONSTYLE+ 패션 대표 상품 9 ×]…(여기서 추가 최대 8)
[주요 지표][통합 분석][체류·반복 분포]…
```
GNB(60) 아래로 **브레드크럼 줄 → 제목 줄 → 프로그램 전환 바 → 섹션 탭 바** 순서. 프로그램 전환 바와 섹션 탭 바는 sticky 라 스크롤 중에도 프로그램을 바꿀 수 있다.

- 브레드크럼 줄: 칩(24h·r6) + KT 히어로 배지 중 홈쇼핑사(로고 포함)·일반채널을 같은 칩 규격으로 이어 붙임
- 제목 줄: ← 되돌아가기 36px 고스트 버튼(→ `schedule.html`) · 제목 · 정보 타일 5칸(KT 그대로)
- **프로그램 전환 바(`.ktprogbar`)** — 26-08-25 에 두 줄(「담은 프로그램」/「타사 비교」)에서 **한 줄 「분석 대상」**으로 합쳤다. 두 줄로 나눴더니 아랫줄 이름 때문에 "위=자사, 아래=타사"로 잘못 읽혔는데, 실제로 갈리는 기준은 **어디서 담았나**다(편성표 ↔ 이 화면). 편성표에서도 타사를 담을 수 있어 앞쪽에도 타사가 섞인다.
  - 앞쪽 = 편성표에서 담은 정본(최대 9), 뒤쪽 = 이 화면의 표·히트맵에서 누른 것(최대 8, `×` 로 뺀다)
  - 둘 사이는 **세로 구분선 1×18**, 뒤쪽 칩은 **점선 테두리 + 연한 바탕**(줄이 접혀도 구분이 남는다. 접혀서 구분선만 줄 끝에 남으면 구분선은 숨긴다)
  - 칩 = 회사 배지 + 프로그램명(+ 같은 이름이 둘 이상일 때만 날짜). **자사(KT알파 쇼핑) 배지만 보라 톤** — 자사/타사는 색으로 읽힌다
  - 활성 = 연보라 바탕 · 보라 글자 · 보더 없음
- KT 히어로 카드(`main > div > header.shadow-panel`)·KT 바구니 바는 내용을 옮긴 뒤 숨김. 뺀 것: "프로그램 상세 분석"·"프로그램별 탭 분석"·"분석 바구니 결과" 라벨(브레드크럼과 중복), 편성 시간 배지(타일과 중복), 설명 문장(보일러플레이트).
- 프로그램 전환 시 KT 가 히어로를 다시 그리면 헤더 존도 다시 그린다(MutationObserver).
- 좌우 패딩 `max(48px, 50vw − 864px)`(1920 에서 96) — 카드 왼선과 같은 기준선

#### 3.2.1 프로그램 전환의 저장 구조 (실서비스에선 이 우회가 필요 없다)
KT 번들은 **부팅 때 세션의 카트를 딱 한 번 읽고, 그중 9개까지만** 탭 버튼으로 그린다. 그래서 타사를 차트에 올리려면 카트를 갈아끼우고 페이지를 다시 들어가는 수밖에 없다. 대신 사용자가 담은 목록이 흔들리면 안 되므로 저장소를 셋으로 갈랐다.

| 키 | 뜻 |
|---|---|
| `gsi-own-list` | 편성표에서 담은 목록 — **정본**. 「분석 대상」 앞쪽은 이것만 그린다 |
| `gsi-cross-list` | 이 화면에서 추가한 타사 목록(상한 8, 오래된 것부터 밀어냄) |
| `gsi-program-analysis-cart` | **지금 차트에 올릴 세트** — 자사를 보는 중이면 own 전체, 타사를 보는 중이면 [기준 자사 1, 그 타사 1] |
| `gsi-cross-open` · `gsi-cross-scroll` | 다시 들어간 뒤 보던 프로그램·스크롤 위치 복원용 |

- 같은 카트 안(기준 자사 ↔ 그 타사)의 전환은 KT 버튼 클릭이라 즉시. 카트를 바꿔야 할 때만 같은 주소로 다시 들어간다(문서 14MB라 0.7~1.2초 흰 화면)
- 복원은 한 번의 `scrollTo` 로는 안 된다 — 차트가 그려지며 위 콘텐츠가 자라고 브라우저의 스크롤 앵커링이 밀어낸다. `overflow-anchor: none` + 문서 높이가 멎을 때까지 같은 자리에 다시 앉힌다
- **실서비스에선 이 구조를 그대로 옮길 필요가 없다.** 상태를 프런트에서 들고 있으면 재진입 없이 탭만 갈아끼우면 된다

### 3.3 섹션 탭 바 (`injectNav`) — 프로그램 전환 바 아래 sticky
- `main section` 의 h2/h3 를 훑어 자동 생성. 라벨 축약표 `LABEL` 참고, 툴팁에 원제
- 섹션 순서는 KT 지정 순서로 강제한다(`SEC_ORDER`, 26-08-24 KT 요구 #1). 화면에서 뺀 섹션은 `SEC_MUTE`/`SEC_HIDE` — **삭제가 아니라 숨김**이라 되살릴 수 있다
- 고정 영역 높이는 **프로그램 전환 바의 실제 높이(`--ktprog-h`)를 따라간다.** 그 바는 뒤쪽 칩이 붙으면 52 → 97 로 커지므로, 앵커 여백(`scroll-margin-top`)과 스크롤스파이 기준선을 고정값으로 두면 제목이 바 뒤로 숨거나 활성 탭이 한 섹션 먼저 넘어간다
- 클릭 → 해당 섹션 스무스 스크롤 · 스크롤스파이(기준선을 지난 마지막 섹션이 활성, 2px 브랜드 밑줄). 숨긴 섹션은 건너뛴다

### 3.4 KT 풋터 (`injectFoot`) · 위로가기 (`injectTopBtn`)
편성표의 `.kt-footer` 마크업 그대로. 위로가기 44px 원형, 우하단 32/32, 400px 이상 스크롤 시 표시.

### 3.5 "채널별 결과 구성" 카드 (`mix3-script`) — 신규 섹션
"채널/프로그램별 유입유출 상세" 바로 다음. 위 표에서 채널·유입수를 읽어(프로그램 전환 시 표가 바뀌면 카드도 재생성) 채널마다 스택 막대 한 줄 — 막대 길이 = 유입량(최대 채널이 우측 합계 칸 앞까지), 색 = 결과 비율(타 채널 이탈 `#CBD5E1` · 방송 종료까지 시청 `#8B5CF6` · 콜 반응 `#FB923C`), 세그먼트 호버 시 같은 종류 강조 + 툴팁, 막대 아래 범례 캡션. 완주·콜은 페이지 KPI(완주 28.4%·콜 2.6%)에 채널별 소폭 편차를 준 데모 파생치 — 실서비스는 채널별 결과 집계 API.

### 3.6 스킨(kt-skin.css) — Tailwind 유틸을 GSI 토큰으로
- 폰트 Pretendard · 자간 −0.5 · 바닥 gray-100(`main.bg-white` 도 gray-100, `min-h-screen` 해제)
- 컨테이너 `max-w-[1500px]` → 1824, 좌우 패딩 48(카드 왼선 96)
- 카드 `.shadow-panel` → 보더 0 · r12 · GSI 쉐도우 `10px 20px 15px rgba(0,0,0,.04)`
- slate 계열 → GSI gray, violet 계열 → Genie Purple `#6941FF` 계열 (매핑표는 파일 안 주석)
- **차트(recharts 인라인 색)는 건드리지 않음** — KT 파스텔 톤 유지 결정

### 3.7 주입 방식에 대한 주의(개발 시 무시해도 되는 것)
Next.js 하이드레이션이 늦게 끝나면 주입 노드를 걷어내므로 MutationObserver + setTimeout(1200/4000) 재삽입 가드가 있다. 링크 클릭은 `*.html` 로 되쓰는 캡처 전용 핸들러(`static-navigation.js`, KT 제공)와 우리 핸들러가 겹쳐 있다. 모두 목업 전용.
